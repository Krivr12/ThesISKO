# ThesISKO Product Overview

## What is ThesISKO?

ThesISKO is a comprehensive thesis/dissertation submission and management platform. It provides a centralized system for students to submit their thesis work, faculty and administrators to review and approve submissions, and manage document templates, requirements, and submission workflows.

## Key Features

- **Student Submissions**: Students can create, submit, and track thesis submissions with status updates
- **Administrative Review**: Admins can review, approve, or reject submissions with feedback
- **Document Management**: Upload and manage thesis files with S3-based storage
- **Templates & Requirements**: Configure document types, submission templates, and requirements
- **User Management**: Role-based access control for Students, Faculty, and Admins
- **Email Notifications**: Automated email communications via Resend and Nodemailer
- **Search & Analytics**: Search submissions and view dashboard statistics
- **Authentication**: JWT-based auth with Passport.js support (local, Google OAuth)
- **File Management**: Presigned S3 URLs for secure file access and downloads

## Core User Roles

- **Student**: Can create submissions, upload files, track status
- **Faculty**: Can review and provide feedback on submissions
- **Admin**: Full system access including user management and configuration
- **Super Admin**: System-level configuration and security management

## Technical Purpose

This is a production application designed to streamline academic thesis submission workflows with security, scalability, and ease of use as core principles.
